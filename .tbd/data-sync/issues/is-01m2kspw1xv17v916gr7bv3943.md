Synthetic gemini-session and gemini-stream fixtures for the Phase 2 adapters, generated from shapes derived from Gemini CLI v0.60.0 source (commit 733edcb), never from the maintainer's own ~/.gemini data. No prompts, paths, project names or ids from real sessions.

Cases to cover, each with urollup's expected totals:

- A plain session: metadata line, user and gemini records, tokens on the assistant records, later $set lastUpdated records.
- Repeated records of one message id (tokens arriving after the record, tool calls appended later): one request, last record wins.
- A gemini record whose tokens field is null, and info, error and warning records: no usage.
- A $set.messages rewrite that repeats every message with its tokens: revisions, not new requests.
- A $rewindTo marker: the rewound requests stay counted, with a diagnostic, and the transcript view drops them.
- The same session in a legacy <sha256> bucket and its slug copy: counted once.
- A legacy whole-file .json session beside the .jsonl it was migrated into: one logical source.
- A --session-file import replaying message ids, timestamps and tokens under a new session id: owned by the original session.
- A subagent file under chats/<parent session id>/ whose parent record's toolCalls carry its agentId: subagent ownership and the spawn edge.
- A bucket carrying non-session files (logs.json, checkpoint-<tag>.json, checkpoints/, logs/session-<id>.jsonl, tool-outputs/, .unreadable- and .tmp- leftovers): ignored without diagnostics beyond the unknown-file count.
- A .project_root marker that does not hash to the session's projectHash: project unknown, with a diagnostic.
- A gemini-stream capture whose result.stats exceed the session file's totals: a coverage check whose surplus is the unrecorded utility usage, with the init session_id linking the two.
- Token edge cases: a record whose total does not equal its parts, nonzero tool tokens, and thoughts larger than output.

Fixtures also feed the ccusage gemini parity cases and the Gemini adapter bead uro-zogi.
