# urollup-core

The accounting core of [urollup](https://github.com/jlevy/urollup): session log
ingestion, reconciliation, querying and report contracts for Claude Code, Codex and Pi
usage.

**Status:** scaffold only.
The crate exposes its version and an empty module skeleton; see the
[design specification](https://github.com/jlevy/urollup/blob/main/docs/urollup-design.md).

The core has no CLI, HTTP or async-runtime dependencies; the `urollup` executable
depends on it as an ordinary dependency.
